# Label Tool · DLabel

แอปเดสก์ท็อปสำหรับติดป้ายกำกับภาพบนเครื่อง เปิดโปรเจกต์เดิมเพื่อทำงานต่อได้ และส่งออกชุดข้อมูลสำหรับ YOLO

## ติดตั้งบน Windows

ใช้ Python 3.10 ขึ้นไป ตัวอย่างคำสั่ง PowerShell จากโฟลเดอร์โปรเจกต์

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe label_tool.py
```

หลังติดตั้งแล้วเปิดด้วย `start_label_tool.cmd` ได้

หากใช้ Auto-label หรือดึงเฟรมวิดีโอ ให้ติดตั้งชุดเพิ่มเติม

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-ml.txt
# เพิ่มสำหรับโมเดล ONNX บน CPU
.\.venv\Scripts\python.exe -m pip install onnxruntime
```

ใช้ไฟล์โมเดลจากแหล่งที่เชื่อถือได้ เลือกไฟล์ local เพื่อรันแบบออฟไลน์ หรือเลือก Official YOLO เพื่อดาวน์โหลด weights ครั้งแรก การรัน TensorRT ต้องมี NVIDIA GPU, CUDA และ TensorRT ที่ตรงกับไฟล์ engine

## ขั้นตอนใช้งาน

1. กด **New project** แล้วสร้างไฟล์ `.dlabel` จากนั้นกด **Add images** หรือ **File → Add image folder** โปรแกรมอ้างอิงไฟล์รูปตามตำแหน่งเดิม เก็บไฟล์รูปไว้ในตำแหน่งนั้นเพื่อเปิดโปรเจกต์ต่อได้
2. กด **+ Class** หรือ **Import** เพื่อนำเข้ารายชื่อจาก `classes.txt` / `data.yaml` ใช้ปุ่มลูกศรจัดลำดับ และ **Merge / delete** เพื่อแก้ข้อมูลทั้งโปรเจกต์
3. ใช้ **B** วาดกล่อง, **P** วางจุด, **G** วาด polygon แล้วกด **Enter** และ **H** เลือกหรือปรับขนาดกล่อง ใช้ **Shift+คลิก** เพื่อเลือกวัตถุจากเครื่องมือวาด ใช้ **K** เพิ่ม keypoint ตามลำดับบนกล่องที่เลือก การแก้ไขบันทึกอัตโนมัติ
4. ตั้งโมเดลใน **Model Manager / Auto-label** เลือก class และ map ไปยัง class ในโปรเจกต์ ใช้ **Preview** ตรวจตัวอย่างกับ class ที่มีอยู่ หรือรันกับรูปปัจจุบัน รูปที่เลือกในแถบล่าง รูป Unlabeled หรือทั้งหมด ผลที่รอตรวจใช้เส้นประ
5. ใช้ **Dataset → Review mode** เพื่อตรวจรูปที่มีผลทำนาย กด **A** ยืนยันทั้งรูป, **R** ปฏิเสธผลทำนาย หรือ **E** แก้ไข กด **N** สำหรับภาพพื้นหลังที่ไม่มีวัตถุ
6. กด **Export YOLO** เลือกเวอร์ชันและสัดส่วน train/val/test โฟลเดอร์ปลายทางต้องเป็นชื่อใหม่ ตัวส่งออกสร้าง `data.yaml`, ตัวอย่าง `train.py` และรายงานชุดข้อมูล ถ้าย้ายโฟลเดอร์ ให้ปรับ `path` ใน YAML หรือลองใช้ตัวอย่าง `train.py` ของ v8/v10/v11 ซึ่งตั้ง path ตามตำแหน่งใหม่ให้ สำหรับ v5 ให้ระบุโฟลเดอร์ YOLOv5 ที่ติดตั้งไว้เมื่อรัน `train.py`

**Import YOLO dataset** อ่านรูปและ label จากโฟลเดอร์ที่แตก ZIP แล้ว รองรับรูปแบบ `images/train` และ `train/images` รวมถึง label คู่รูป หากมีรูปอยู่ในโปรเจกต์แล้ว โปรแกรมจะนำเข้า label เฉพาะรูปที่ยังเป็น Unlabeled

## วาดกรอบทีละรูป

กด **B** เลือกเครื่องมือ Box แล้วกด **1–9** เลือกคลาส จากนั้นกด **F8** หรือปุ่ม **Auto-next box** เหนือแถบรูป เมื่อวาดกรอบเสร็จ โปรแกรมจะบันทึกกรอบและเปิดรูปถัดไปที่ยังเป็น **Unlabeled** ในรายการที่กำลังดู โดยใช้คลาสเดิม

ถ้ารูปหนึ่งต้องวาดหลายกรอบ ให้กด **F8** ปิดโหมดชั่วคราว ใช้ **Page Up / Page Down** หรือ **A / D** เพื่อเลื่อนรูป และกด **F1** เพื่อดูคีย์ลัดทั้งหมด

## Auto-label จากข้อความ

หลังติดตั้งชุด Auto-label แล้ว ให้เพิ่มตัวอ่านคำค้นสำหรับ YOLO-World

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-text.txt
```

1. สร้างหรือเลือกคลาสในโปรเจกต์ เช่น `rainbow` หรือ `สายรุ้ง`
2. เปิด **Model Manager / Auto-label** เลือก **Text prompt (YOLO-World)** แล้วกด **Continue**
3. ในคอลัมน์ **What to find (text prompt)** พิมพ์ `rainbow` ในแถวคลาสที่ต้องการบันทึกผล เว้นแถวอื่นให้ว่างถ้าต้องการข้าม
4. เลือก **All images** เพื่อรันทั้งชุด หรือเปิด **Preview** เพื่อทดลองไม่เกิน 5 รูป แล้วกด **Run** ผลที่บันทึกจะอยู่ในสถานะ **Predicted** เพื่อให้ตรวจและอนุมัติก่อน export

ใช้รูปที่ยังไม่มี label ได้เลย ครั้งแรกต้องดาวน์โหลด weights ของ YOLO-World และตัวอ่านคำค้น CLIP จากนั้นประมวลผลรูปในเครื่อง ใช้คำภาษาอังกฤษสั้น ๆ และตรวจความถูกต้องของกรอบก่อนนำไปเทรน

## เทรนโมเดลจากในโปรแกรม

1. เปิดโปรเจกต์แล้วเลือก **Model → Train Dataset…** จากนั้นเลือก `data.yaml` จากโฟลเดอร์ที่ Export แบบ **YOLO Detect** ชุดข้อมูลต้องมีรูปใน Train และ Validation และมีกรอบอย่างน้อยหนึ่งกรอบใน Train
2. เลือก weights เริ่มต้น จำนวน **Epochs** ขนาดภาพ และ **CPU** หรือ **GPU 0 (CUDA)** แล้วกด **Start training** ค่าเริ่มต้นใช้ `yolo11n.pt`
3. เมื่อเสร็จ กด **Use for Auto-label** เพื่อจับคู่คลาสของโมเดลกับคลาสในโปรเจกต์และเลือกรูปที่จะรัน

ผลแต่ละครั้งและ `training.log` อยู่ในโฟลเดอร์ `training-runs` ข้างไฟล์โปรเจกต์ โมเดลสำหรับนำกลับมาใช้คือ `weights/best.pt` ของรอบนั้น

## Your Models และการเลือกคลาส

เปิด **Model → Your Models…** เพื่อเลือกโมเดลที่บันทึกไว้ หรือกด **Add model…** เพื่อเลือกไฟล์ `best.pt` จากเครื่อง โมเดลที่เทรนเสร็จในโปรแกรมจะเพิ่มในรายการของโปรเจกต์นั้นโดยอัตโนมัติ

ใน **Model Options** ใช้ **Enabled** เปิดหรือปิดคลาสที่โมเดลจะตรวจ และใช้ **Label as** เลือกหรือพิมพ์ชื่อคลาสที่จะบันทึกในโปรเจกต์ กด **Save settings** เพื่อจำการตั้งค่าโดยยังไม่รัน หรือกด **Run** เพื่อเริ่ม Auto-label

## ขอบเขต

- กล่องและจุดอิสระเป็นพิกัดพิกเซลในโปรเจกต์ จุดอิสระเลือกข้าม แปลงเป็นกล่องคงที่สำหรับ detect หรือแยกเป็น CSV ได้
- การ export รองรับ detect สำหรับ v5/v8/v10/v11/v26, seg สำหรับ v5/v8/v11/v26 และ pose สำหรับ v8/v11/v26 ลำดับ keypoint บนแต่ละกล่องควรตรงกันทั้งชุด
- Auto-label ใช้โมเดล detect เท่านั้น การนำเข้าวิดีโอรองรับไฟล์ในเครื่องและกำหนด FPS ที่ต้องการได้
- สคริปต์เดิม `auto_label_yolov.py` ยังใช้แยกได้สำหรับงาน batch ควรใช้ปลายทางใหม่สำหรับ CLI เดิม เพราะสคริปต์จะเขียนทับโฟลเดอร์ปลายทางเดิม
- งานใน roadmap ที่ยังไม่รวม ได้แก่ SAM, OBB, tracking, COCO/VOC, dataset versioning, augmentation และ dashboard
